## Армии и поток
- Скорость юнита: 0.12 ширины поля в секунду *(на телефоне путь через весь экран ≈ 8 сек)*.
- Отправка (только свайп): 75% войск узла. Округление вниз, минимум 1, в узле остаётся хотя бы 1, нельзя отправить из узла с 1 юнитом и из атакованного узла. ИИ: атака и защита — 75%, подтягивание из тыла — 50% (внутренний режим `pull`).
- Константы потока — `STREAM` в `balance.ts`:

| Параметр | Значение | Смысл |
|---|---|---|
| `releasePerSec` | 5 | темп выхода, юнитов в секунду. Шаг между юнитами = скорость / темп = 0.024 ширины поля |
| `width` | 1 | ширина колонны (зарезервировано под будущие улучшения; сейчас всегда 1) |
| `attackWindowMs` | 1000 | узел считается атакованным ещё столько после прихода последнего врага |
| `pauseSourceProduction` | false | производство источника во время выпуска идёт (решено, GDD §3.6); флаг — только рычаг баланса |
| `contactDist` | 0.01 | расстояние касания юнитов разных сторон, доля ширины поля |
| `edgeDist` | small 0.035, medium 0.044, large 0.054 (0.04 / 0.05 / 0.062) | на каком расстоянии от центра узла юнит появляется и приходит, доля ширины поля. Чуть меньше радиуса круга (`NODE_RADIUS` в `game.ts`: 0.048 / 0.059 / 0.073, до PLAYTEST-2 — 0.055 / 0.068 / 0.084; узлы −13%, F2-2), чтобы фигурка появлялась ещё под кругом |

- **Шаг колонны — свойство дороги**, а не потока: юнит выходит на дорогу (в одном направлении), только если предыдущий вышедший на неё отошёл на `ARMY.speed / releasePerSec` от точки выхода. Поэтому темп `releasePerSec` — это и максимальная пропускная способность дороги. Тик 100 мс: за тик юнит проходит 0.012, шаг 0.024 — за тик на дорогу выходит не больше одного юнита (проверяется тестом баланса).
- Удар огненного шара, мага и дракона ставит окно атаки так же, как пришедший враг.
- Путь юнита по дороге стал короче на `edgeDist` с каждой стороны: атаки чуть быстрее, чем при выходе из центра.

- Ориентир по времени: типичная отправка ~18 юнитов выходит за ~3.6 с, колонна длиной ~0.43 ширины поля.
