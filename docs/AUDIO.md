# Музыка и звук

Статус: v0.2. Сделаны A-1, A-2 и A-4: музыка — `src/view/music.ts`, выбор трека — `src/core/audio/playlist.ts`, эффекты из файлов — `src/view/sound.ts`. Список файлов, которые есть в проекте, — `MUSIC.files` и `SFX.files` в `src/config/game.ts`: новый трек играет после того, как его ID дописан туда. A-3 (титры) — не нужна, пока нет треков CC BY.

Документ состоит из двух частей:
1. **Реестр треков** — какой трек где играет, откуда он и на каких условиях. Заполняется по мере подбора музыки.
2. **Задачи для Claude Code** — как подключить музыку в игру (этапы A-1 → A-4, каждый — отдельный PR).

## Общие правила (дополняют CLAUDE.md)

- **Исключение из правила 8 CLAUDE.md:** музыку кодом не генерируем — это аудиофайлы. Звуковые эффекты по-прежнему синтезируются в `sound.ts`, пока в реестре не появится замена.
- Добавлять в игру только треки со статусом **✅ готов** в реестре. Трек без заполненных «Источник» и «Лицензия» в билд не попадает.
- Лицензии: **CC0**, **Pixabay Content License**, **CC BY** (с указанием автора в титрах). **Нельзя:** CC BY-NC (игра с рекламой — коммерческая), CC BY-ND с правкой трека, «free for personal use».
- Треки с пометкой **YouTube Content ID** не берём (заявки на трейлеры и видео блогеров). Исключение — только по явному решению, с отметкой в реестре.
- Подтверждение лицензии: ссылка на страницу трека + скриншот лицензии на дату скачивания в `docs/audio-licenses/<id>.png`.

## Технические требования к файлам

- **Формат:** MP3, 44.1 кГц. Музыка — 96–128 кбит/с, стерео допустимо; джинглы — 96 кбит/с.
- **Громкость:** нормализация ~−16 LUFS для музыки, джинглы на ~2 дБ громче. Пики не выше −1 dBTP.
- **Цикл:** у музыки начало и конец сведены без щелчка и паузы (проверить на трёх повторах подряд). Тишину в начале/конце обрезать.
- **Длина музыки:** 1–3.5 мин. Бюджет на всю музыку — **≤ 12 МБ**; каждый трек грузится отдельно и только когда нужен (см. A-1), поэтому на скорость старта не влияет.
- **Расположение:** `public/audio/<id>.mp3` (Vite копирует как есть; пути относительные — `base: './'`).
- **Имена файлов:** строго по ID из реестра.

## A-1. Инфраструктура музыки

- Модуль `src/view/music.ts` рядом с `sound.ts`: `playMusic(id)`, `stopMusic(fadeMs)`, `playJingle(id)`, `setMusicEnabled(on)`, `setMusicSuspended(value)`. На Phaser Sound Manager (`game.sound` уже ставится на паузу в `main.ts`) или Web Audio — на выбор, но одна точка входа.
- Повторный `playMusic` того же трека не перезапускает его (переход меню → карта → прокачка без обрыва).
- Смена трека — кроссфейд ~500 мс. Громкость музыки — константа в `src/config/game.ts` (рядом с `SFX.volume`).
- **Загрузка не тормозит старт:** музыка грузится в фоне после `LoadingAPI.ready()`, по одному треку — сначала `music_menu`, остальные при первом заходе в сцену; если трек ещё не загружен — играет, как только загрузится. Нет файла (трек ещё ⬜) — тишина без ошибок.
- **Пауза:** при скрытии вкладки и рекламе — полная пауза (требование Яндекса, тот же механизм, что `setSoundSuspended`). В панели паузы боя — музыка приглушается до ~40%, не останавливается.
- **Настройки:** отдельный переключатель «Музыка» рядом со «Звуком» в паузе боя и в меню. Поле `music: boolean` в настройках `SaveData` (закрывает `TODO(stage-7)`), с миграцией версии сохранения и тестом.
- **Готово, когда:** с любым тестовым MP3 в `public/audio/music_menu.mp3` музыка играет в меню, переживает переходы, выключается в настройках, ставится на паузу при скрытии вкладки; без файлов игра работает молча.

## A-2. Музыка по сценам

- `MenuScene` → `music_menu`.
- `ChapterMapScene` и `UpgradesScene` → `music_upgrades` (нет файла — `music_menu`). **Переходы карта ↔ прокачка не перезапускают трек:** музыка продолжает играть с того же места, без кроссфейда и паузы (это частный случай правила «повторный `playMusic` того же трека не перезапускает его» из A-1). Переход главное меню ↔ карта/прокачка — смена трека с кроссфейдом.
- **Готово, когда:** карта → прокачка → карта → прокачка — музыка звучит непрерывно, без рывков и начала заново.
- `BattleScene` → один из `music_battle_N` по ротации: N = ((номер уровня в главе − 1) mod число_треков) + 1, считаются только треки, у которых есть файл. Один и тот же уровень всегда звучит одинаково; «Ещё раз» не меняет трек, «Дальше» — переход на трек следующего уровня с кроссфейдом. Список боевых треков — массив в `src/config/game.ts`, чтобы добавить трек, достаточно положить файл и дописать ID.
- На уровнях с боссом (10-е) → `music_boss`, если есть файл, иначе по общей ротации.
- Конец боя (`endBattle`): фейд музыки за ~300 мс; джингл — в момент появления панели результата (после `RESULT_DELAY_MS`), не в момент захвата последнего узла. Синтезированные `victory`/`defeat` из `sound.ts` при наличии джингла не играют.
- Джингл победы зависит от звёзд за бой: 3 звезды → `jingle_victory_3star` (нет файла — `jingle_victory`), 1–2 звезды → `jingle_victory`. Звёзды уже считаются к моменту показа панели — брать оттуда же, откуда их берёт панель результата.
- Глава пройдена → `jingle_chapter` вместо джингла победы (нет файла — джингл победы по звёздам).
- Выход с панели результата на карту → `music_upgrades` (или боевой трек при «Дальше» / «Ещё раз»).
- Ускорение ×2 музыку не меняет.

## A-4. Звуковые эффекты из файлов

- В `sound.ts`: необязательный файл для каждого `SfxId` (`public/audio/sfx_<id>.mp3`, список ID с файлами — в `src/config/game.ts`). Файлы эффектов маленькие — грузить и декодировать (`decodeAudioData`) сразу после `LoadingAPI.ready()`, до первого клика.
- `playSfx(id)`: если буфер файла загружен — играть его (через тот же `master`, с теми же правилами mute/suspend), иначе — синтезированный вариант, как сейчас. Публичный API `playSfx` не меняется.
- Громкость файловых эффектов — отдельная константа рядом с `SFX.volume`, подобрать на слух вместе с музыкой.
- Клик не должен запаздывать: проверить на телефоне, что звук совпадает с нажатием (MP3-кодер добавляет ~25 мс в начале; если слышна задержка — пропускать начало буфера через `start(when, offset)`).
- **Готово, когда:** клик по любой кнопке играет `sfx_click.mp3`; если файл удалить — играет синтезированный клик, ошибок нет.

## A-3. Титры

- Если все треки CC0 / Pixabay — задачу пропустить.

## Как добавляется трек

1. Никита присылает трек и говорит, где он будет играть.
2. Трек проверяется: длина, громкость, цикл, лицензия, Content ID. При необходимости — обрезка, нормализация, конвертация в MP3.
3. Файл кладётся в `public/audio/<id>.mp3`, строка в реестре заполняется, статус → ✅.
4. ID трека дописывается в `MUSIC.files` (эффекты — в `SFX.files`) в `src/config/game.ts`, после этого он играет в игре.
