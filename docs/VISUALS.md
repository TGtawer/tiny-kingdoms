# Живые экраны: главное меню и карта глав

Статус: v0.2 — V-1 сделан. Задача — оживить главное меню и карту глав анимацией в стиле игры (всё рисуется кодом, как сейчас).

**Визуальный эталон** — интерактивный прототип `docs/prototypes/living-screens.html` (открыть в браузере). Там нарисован каждый эффект из этого документа, с переключателями и кнопками «Показать анимацию входа» / «Показать открытие уровня». Прототип написан на Canvas 2D, а не на Phaser: брать из него **внешний вид, размеры, цвета и тайминги**, а не код. Где документ и прототип расходятся — прав документ.

Делать по этапам **V-1 → V-3**, каждый — отдельная ветка/PR.

## Общие правила (дополняют CLAUDE.md)

- Все правила из `CLAUDE.md` действуют. Это чисто визуальная работа: правила игры в `src/core/` не меняются.
- Все размеры, скорости, тайминги и цвета — константы в `src/config/game.ts` (новые блоки `MENU_FX` и `MAP_FX`), не в коде сцен.
- **Производительность (цель — 60 FPS на слабом Android):**
  - статичные картинки (декор, облака, тени облаков) рисуются в `Graphics` **один раз** и превращаются в текстуру (`generateTexture`); дальше двигаются спрайты твинами или в `update`;
  - никаких перерисовок `Graphics` каждый кадр, кроме дешёвых линий (штрихи дороги);
  - всё, что крутится в `update`, останавливается на `SHUTDOWN` сцены; твины убиваются при пересборке (`build()` на resize).
- Эффекты не мешают вводу: декор, облака, птицы и фоновый бой не интерактивны, тап по уровню на карте работает как сейчас.
- Каждый эффект можно выключить флагом в `MENU_FX` / `MAP_FX` (для отладки производительности).
- Проверка в портрете 360×640 и альбоме 1280×720, плюс resize на лету — ничего не дублируется и не съезжает.
- После этапа: `npm run lint && npm run test && npm run build`.

## V-1. Главное меню (`MenuScene`)

Уже есть: луг с цветами (`drawMeadow`, `drawFlowers`), покачивание заголовка, панель с кнопками, переключатели звука и музыки, счётчик кристаллов.

### 1.1 Бой ИИ против ИИ на фоне
- Под панелью и заголовком идёт настоящий бой: две стороны под управлением `EnemyAI`, тот же `World`, `step`, `NodeView`, `ArmyView`, `RoadView`, эффекты захвата (`ringBurst`, `pop`). Игрок в нём не участвует, ввод не принимается.
- Уровень фона — отдельный JSON `src/levels/menu_background.json` по обычной схеме (валидация в `tests/levels.test.ts`), **не входит** в главы и `ALL_LEVELS`. 7–8 узлов: столица синих в одном углу, красных — в противоположном, нейтралы между ними; узлы стоят по краям экрана, чтобы бой был виден сверху и снизу от панели (см. прототип).
- Обе стороны — `createAi` с одинаковой средней агрессией; seed случайный при каждом входе в меню, чтобы бой каждый раз шёл по-разному.
- Когда одна сторона забрала все узлы (или прошло `MENU_FX.battleMaxSec`, ~120 с) — через 3 с плавный фейд (0.5 с) и новый бой.
- Узлы фона чуть меньше боевых (радиусы 18 / 21 / 24 px для малого / среднего / большого в 360×640). Числа войск видны.
- Звук фонового боя **выключен** (никаких `playSfx` из этой сцены, кроме кнопок).
- Фон ставится на паузу, когда сцена неактивна, и уничтожается на `SHUTDOWN`.
- **Готово, когда:** в меню без касаний идёт бой, армии ходят, узлы перекрашиваются, бой перезапускается сам; FPS не падает относительно текущего меню.

### 1.2 Дымка поверх боя
- Прямоугольник цвета луга (`COLORS.background`) с альфой ~0.42 на весь экран между фоновым боем и UI. Цветы и трава — под боем.

### 1.3 Тени облаков
- 3 большие мягкие тени (группа из 3–4 эллипсов, тёмно-зелёный, альфа ~0.10), один раз в текстуру. Плывут слева направо со скоростью 5–9 px/с, уходя за край — возвращаются слева. Рисуются поверх фонового боя и дымки, под UI.

### 1.4 Птицы
- Пара птиц («галочки» цвета `COLORS.outline`, 2 px) раз в 6–12 с пролетает через верхнюю треть экрана за ~7 с, в случайную сторону. Крылья машут (сдвиг концов по синусу, ~11 рад/с). Вторая птица чуть позади и ниже, со сдвигом фазы.

### 1.5 Блик на заголовке
- Раз в 4 с по заголовку за 0.8 с проходит наклонная светлая полоса (белый градиент, ~60 px шириной, наклон ~20°), видимая только поверх букв. В Phaser: маска по тексту заголовка (`BitmapMask` с самим текстом или копией) и спрайт-полоса, которую двигает твин.
- Существующее покачивание заголовка и тень остаются.

### 1.6 Пульс кнопки «Играть»
- После окончания анимации входа кнопка «Играть» плавно дышит: масштаб 1 → 1.035, период 1.6 с, `Sine.InOut`. Вместе с масштабом — мягкое золотое свечение за кнопкой (скруглённый прямоугольник на 7 px больше кнопки, `#ffe078`, альфа 0 → 0.45 в такт).
- Нажатие работает как сейчас; на время нажатия пульс не мешает анимации `Button`.

### 1.7 Анимация входа
- При каждом входе в меню (старт игры, возврат с карты / прокачки / из боя):
  - заголовок падает сверху (с ~140 px выше своего места) за 0.6 с, `Back.Out`;
  - переключатели звука и кристаллы проявляются за 0.3 с;
  - панель появляется с 0.15 с: альфа 0 → 1 и масштаб 0.9 → 1 за 0.35 с, `Back.Out`;
  - три кнопки выезжают снизу на 60 px по очереди: старт 0.30 / 0.39 / 0.48 с, длительность 0.32 с, `Back.Out`;
  - покачивание заголовка и пульс «Играть» начинаются после окончания входа.
- При resize вход не повторяется — элементы сразу на местах.
- Кнопки нажимаются уже во время анимации.

### 1.8 Кнопки и переключатели (добавлено при реализации)
- **Все кнопки игры** (`src/view/Button.ts`) рисуются как в прототипе: мягкая тень снизу (сдвиг 5 px, альфа 0.35), лицевая часть цвета кнопки, постоянный блик в верхней трети (белый, альфа 0.22), обводка 3 px, скругление 16 px. При нажатии лицевая часть опускается на 3 px. Числа — `BUTTON_STYLE` в `src/config/game.ts`.
- Переключатели звука и музыки в меню — круглый вариант того же стиля: 44 px (зона касания 48 px), тень, блик-эллипс сверху, при нажатии опускаются; иконки динамика и ноты как в прототипе, выключенный перечёркнут.
- Стрелка «Назад» нарисована толстыми линиями со скруглёнными концами.

### Отличия реализации V-1 от текста выше
- **Блик заголовка (1.5)** сделан без маски: в Phaser 4 маски — WebGL-фильтры с отрисовкой каждый кадр. Заголовок рисуется в canvas-текстуру (`src/view/ShinyTitle.ts`), полоса обрезается по буквам через `source-atop`, текстура перерисовывается только пока идёт полоса.
- **Фоновый бой (1.1)** идёт на скорости 0.6 от обычного (`MENU_FX.battle.simSpeed`): на маленьком поле меню армии с обычной скоростью двигаются почти вдвое быстрее, чем в прототипе.

## V-2. Карта глав: окружение (`ChapterMapScene`)

Уже есть: извилистая дорога, узлы уровней (пройден / текущий / закрыт), галочки и звёзды, пульс текущего уровня, прокрутка.

### 2.1 Отряд над текущим уровнем
- Над текущим уровнем стоит фишка игрока — синий маркер как `ArmyView` (без числа, радиус ~13 px), подпрыгивает: высота 0–10 px по `|sin|`, период ~1 с. Под ним тень-эллипс, которая сжимается, когда фишка в воздухе.
- Если вся глава пройдена — фишка стоит над последним уровнем.

### 2.2 Дорога: пройдено и впереди
- Отрезки дороги между пройденными уровнями — как сейчас.
- Отрезки после текущего уровня — та же дорога с альфой ~0.5.
- На отрезке от последнего пройденного уровня к текущему — бегущие белые штрихи поверх дороги: штрих 10 px, промежуток 12 px, толщина 4 px, скорость ~28 px/с в сторону текущего уровня. В Phaser — `Graphics`, перерисовка только этого отрезка каждый кадр (дёшево) или `TileSprite` с текстурой штриха, повёрнутый вдоль отрезка.

### 2.3 Декор
- Вдоль пути расставлены: лиственные деревья, ёлки, кусты, домики, пруды (до 2), мельницы (до 2). Всего ~45 штук на главу. Стиль — как в прототипе: заливка + обводка `COLORS.outline` 2 px, тень-эллипс снизу.
- Расстановка детерминированная (seed = номер главы), с отступами: ≥ радиус узла + 22 px от узлов, ≥ 14 px от дороги, без наложений друг на друга. Чистая функция расстановки — в `src/view/` (или `src/core/`, если удобно покрыть тестом: «ни один предмет не пересекает узлы и дорогу»).
- Каждый тип рисуется **один раз** в текстуру; на карте — спрайты, отсортированные по Y (нижние перекрывают верхние). Пруды — под дорогой, остальное — над дорогой, под узлами.
- Позже палитру декора можно менять по главам (TODO, не в этом PR).

### 2.4 Покачивание и мелкая жизнь
- Кроны деревьев и ёлки покачиваются: поворот ±2° вокруг основания, период ~4 с, у каждого своя фаза. Для этого крона и ствол — разные спрайты, или origin спрайта у основания.
- Крылья мельниц вращаются (~1.4 рад/с) — отдельный спрайт крыльев.
- Из труб домиков поднимается дымок: кружок растёт и тает за 2 с, по кругу.

### 2.5 Облака с параллаксом
- 6–8 белых облаков (группа эллипсов, альфа ~0.92) с тенью снизу-справа (тёмно-зелёный, альфа ~0.12). Один раз в текстуру.
- Облака лежат над картой, но под верхним баром и нижней полосой. Медленно дрейфуют вбок (4–10 px/с), а при прокрутке карты сдвигаются в 1.4 раза быстрее земли (`scrollFactor` ≈ 1.4) — это даёт глубину.
- Облака не перекрывают текущий уровень надолго: альфа облаков ≤ 0.92, и они не интерактивны (тап проходит к уровню).

### 2.6 Отряд гуляет по пройденному пути
- Маленький синий отряд (как `ArmyView`, без числа, радиус ~8 px) ходит по дороге от первого уровня до последнего пройденного и обратно, ~4.2 с на отрезок, слегка подпрыгивая на ходу. Если пройден меньше чем 2 уровня — не показывается.

## V-3. Карта глав: открытие уровня после победы

Главный «вау-момент» карты. Посмотреть: кнопка «Показать открытие уровня после победы» в прототипе.

### 3.1 Когда играет
- Игрок **впервые** прошёл уровень и с панели результата нажал «К карте». `BattleScene` передаёт в `ChapterMapScene` данные: `{ reveal: { levelId, stars, previousStars, unlocked: boolean } }`.
- `unlocked = true`, если победа открыла следующий уровень (первое прохождение). При повторной победе с улучшением звёзд — только анимация новых звёзд (шаг 0–0.9 с), без дороги и замка.
- «Дальше» (сразу в следующий бой) анимацию не показывает. Вход на карту из меню — тоже.
- Карта при входе с `reveal` рисуется в состоянии **до** победы (уровень — текущий, следующий — закрыт), затем анимация переводит её в новое состояние. Прогресс к этому моменту уже сохранён (как сейчас) — анимация только визуальная.

### 3.2 Таймлайн (секунды от входа на карту)
| Время | Что происходит |
|---|---|
| 0.0 | Пройденный уровень: золотой → синий, `pop` (масштаб до 1.16 и обратно за 0.25 с) + `ringBurst` синего цвета. |
| 0.15–0.45 | Галочка появляется, `Back.Out`. |
| 0.35 / 0.60 / 0.85 | Звёзды по одной вырастают из 0 (`Back.Out`, 0.3 с). На каждую заработанную — искры (8 золотых точек разлетаются на ~25 px за 0.5 с). |
| 0.9–2.3 | Камера плавно (`Sine.InOut`) едет так, чтобы следующий уровень оказался в центре видимой области. Ввод прокрутки на время анимации отключён. |
| 1.1–1.9 | Дорога к следующему уровню «прорисовывается»: от пройденного узла к следующему растёт непрозрачный отрезок поверх приглушённого. |
| 1.9–2.4 | Замок на следующем уровне трясётся (±3 px по X, нарастая за 0.2 с). |
| 2.4 | Замок раскалывается: две половинки разлетаются в стороны по дуге, вращаясь, и исчезают за 0.7 с. Узел становится золотым (текущим), вырастает из 0 (`Back.Out`, 0.35 с), номер уровня появляется, `ringBurst` золотой + 12 искр. |
| 2.6–3.4 | Фишка игрока (2.1) перепрыгивает с пройденного уровня на новый: три прыжка по ~22 px вверх вдоль дороги. |
| 3.5 | Анимация закончена: включаются пульс текущего уровня, бегущие штрихи (2.2), прокрутка. |

- Тап по открывшемуся уровню во время анимации запускает его сразу (анимация не должна задерживать игрока).
- Если последний уровень главы — шаги с дорогой и замком пропускаются.

### 3.3 Звук
- Звёзды — по короткому «дзынь» на каждую заработанную, разлом замка — `capture`. Пока отдельных эффектов нет: использовать существующие `SfxId` (`build` для звёзд, `capture` для замка) и оставить `TODO(audio)` — файлы будут добавлены через `docs/AUDIO.md`.
