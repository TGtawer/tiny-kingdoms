# Плейтест 1: исправления главы 1

Статус: v0.1 — решения утверждены после плейтеста главы 1 (ноябрь 2026). Документ — список задач для Claude Code, этапы F-1…F-8.

Каждый этап — **отдельная ветка и отдельный PR**, чтобы его можно было сразу проверить на плейтесте. Этапы по возможности независимы; порядок важен только там, где указана зависимость. Внутри этапа задачи идут в указанном порядке.

## Общие правила (дополняют CLAUDE.md)

- Все правила `CLAUDE.md` действуют: логика — в `src/core/` без Phaser и с тестами; числа баланса — в `src/config/balance.ts`; размеры, цвета и тайминги рендера — в `src/config/game.ts`; весь текст — через i18n (`ru.json` + `en.json`, ключи добавлять в оба).
- `docs/GDD.md`, `docs/BALANCE.md`, `docs/TUTORIAL.md` уже обновлены под решения ниже. Если найдёшь расхождение — правь документ под этот файл и напиши об этом в PR.
- Числа — стартовые, их подбирают на плейтесте.
- После этапа: `npm run lint && npm run test && npm run build`, проверка в портрете 360×640 и альбоме 1280×720.
- Где этап меняет баланс, прогнать `tests/levels.test.ts`, вернуть главу 1 в коридоры побед (`BALANCE.md`) и записать итог в `BALANCE.md` разделом «После F-N».
